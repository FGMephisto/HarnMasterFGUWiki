# HarnMaster 3.5E for Fantasy Grounds Unity

Welcome to the documentation for the **HarnMaster 3.5E** ruleset for [Fantasy Grounds Unity](https://www.fantasygrounds.com/).

This ruleset implements the HarnMaster 3rd Edition rules (with 3.5 customizations) for Fantasy Grounds Unity, focusing on gritty, realistic combat mechanics, detailed injury tracking, and an authentic percentile-based skill system.

---

## Key Features

* **Detailed Hit Location System**: Full implementation of HarnMaster's hit location tables with zone targeting (High, Mid, Low) and specific body part tracking.
* **Automated Combat Resolution Matrix**: Automated calculation of attacker vs. defender outcomes (Critical/Marginal Success & Failure) using official HarnMaster combat matrices.
* **Realistic Injuries & Healing**: Direct generation of injuries (Minor, Serious, Grievous), blood loss, shock checks, and automated Medical Resolution.
* **Skill-Based Character Management**: Percentile checks (ML vs. D100), Skill Base (SB) calculations from attributes, Sunsign modifiers, and development tracking.
* **Magic & Mystic Powers**: Chantry/Convocation spellcasting and ritual tracking.

## Installation

1. Download the latest release or clone the repository.
2. Place the `HarnMaster3.5E` directory into your Fantasy Grounds `rulesets/` folder:
    * **Windows**: `%APPDATA%\SmiteWorks\Fantasy Grounds\rulesets\`
    * **Mac / Linux**: Check your Fantasy Grounds Unity settings for the data directory.
3. Restart Fantasy Grounds Unity.
4. Create a new campaign and choose **HarnMaster** as the ruleset.
